## Перенос в свой Git

1. Распакуйте ZIP и откройте папку `kontur-work` в VS Code (**File → Open Folder**).
   Корнем должна быть папка с `package.json` и `AGENTS.md`.
2. Создайте пустой **приватный** репозиторий у своего Git-провайдера. Архив не
   содержит `.git` и прежние credentials, поэтому история начинается с вашего
   первого коммита. Авторизуйтесь штатным SSH-ключом/credential manager провайдера.
3. Выполните во встроенном терминале VS Code из этой папки:

```bash
git init -b main
git add .
git status --short
git commit -m "Import Kontur Work 0.18.0 with development handoff"
```

Затем добавьте адрес **своего** репозитория (замените URL):

```bash
git remote add origin https://YOUR-GIT-SERVER/YOUR-TEAM/kontur-work.git
git push -u origin main
```

Если Git просит имя и email, задайте свою рабочую идентичность. Если репозиторий
уже содержит код, импортируйте файлы в отдельную ветку его клона; не применяйте
`push --force`. Ни токен, ни пароль не следует записывать в URL remote.

## Выбрать запуск

| Цель | Инструкция |
| --- | --- |
| Разработка с горячим обновлением, сервер и worker в VS Code | [DEVELOPMENT.md](docs/DEVELOPMENT.md) |
| Все компоненты на одном Docker-сервере | [Standalone](deploy/standalone/README.md) и `.env.example` |
| Kubernetes и внешние MySQL/PostgreSQL, Redis и S3 | [Helm](deploy/helm/kontur-work/README.md) |
| Перенос существующей БД и обновление | [DATABASE-UPGRADES.md](docs/DATABASE-UPGRADES.md) |

Для VS Code потребуются Node.js 22.13+ (рекомендуется ветка 22), Git,
Docker Engine 24+/Compose v2 или Docker Desktop. На Windows можно использовать
PowerShell; для Docker и Linux-инструментов также подходит VS Code в WSL2.
После открытия папки доступны **Terminal → Run Task** и **Run and Debug**.
Задачи ничего не запускают автоматически при открытии проекта.

## Передать контекст новому ИИ-помощнику

`AGENTS.md` — корневые инструкции для Codex и совместимых помощников. Регистр
имени важен: файл называется именно **AGENTS.md**. Другим расширениям при
необходимости явно передайте этот файл как контекст. Начальное сообщение:

> Прочитай AGENTS.md, docs/HANDOFF.md и docs/DEVELOPMENT.md. Продолжаем Контур
> Work 0.18.0 из этого репозитория. Проверь текущую ветку и изменения, предложи
> ближайший конкретный шаг с учётом списка непроверенных сценариев. Сохрани
> русский интерфейс, MySQL, Docker/Helm и существующую модель прав.

## Что переносится отдельно

В комплекте нет рабочих паролей, `.env`, данных MySQL/Redis, вложений и записей
S3, ключей VAPID, настроек вашего домена и корпоративных credentials. Для новой
тестовой установки создайте собственные значения. Для продолжения **существующей**
установки отдельно перенесите её БД, S3 и секреты, особенно `APP_ENCRYPTION_KEY`:
с новым ключом старые зашифрованные настройки не расшифруются.

Подробное состояние, карта кода, проверки и следующий этап: [HANDOFF.md](docs/HANDOFF.md).
