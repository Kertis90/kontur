# Контур Work 0.13.0

Добавлен самостоятельный раздел «Интеграции» в боковой навигации и администрировании. Каталог использует общее оформление Контур, адаптивные карточки и анимации с учётом уменьшенного движения.

- Telegram, Mattermost, Slack и подписанные webhooks: конфигурация проекта и событий, секретные реквизиты, пауза, удаление и тестовая отправка.
- Единая точка входа для существующих GitHub/GitLab; прежние webhooks/API сохранены отдельно.
- Права просмотра, настройки, тестов/повторов и журнала для ролей пользователей и групп; отдельные scopes API.
- Доставка через MySQL, атомарная аренда для нескольких worker, повтор временных ошибок, журнал и неизменяемый снимок сообщения.
- Шифрование секретов, проверка прав перед отправкой, HTTPS и защита от SSRF с закреплением проверенного IP. Для корпоративных адресов есть серверный список точных hostname.
- API-методы добавлены в интерактивную документацию и OpenAPI. [Полное руководство](INTEGRATIONS.md).

## Обновление

Сделайте резервную копию БД и сохраните `.env`, ключ шифрования, имя Compose-проекта и рабочие тома. Соберите/опубликуйте образ 0.13.0 для migrate, приложения и всех worker. Примените миграцию `021_integrations.sql` штатным мигратором до запуска новой версии. Миграция создаёт две таблицы, не содержит триггеров и не меняет контрольные суммы 001–020. Исправление незавершённой 013 включено; при диагностике используйте [DATABASE-UPGRADES.md](DATABASE-UPGRADES.md).

Compose и Helm уже передают список внутренних получателей; дополнительные компоненты не нужны. Worker должен иметь исходящий доступ к DNS и HTTPS-получателям. Подключения не создаются и не включаются автоматически.

## Проверка

Локально прошли 158 Node-тестов (19 новых для интеграций), проверка качества и production-сборка Next.js. Отдельные тесты интеграций используют изолированные заглушки БД и транспорта, без отправки в реальные чаты. MySQL/Docker/Helm, внешние каналы и визуальный просмотр требуют доступного стенда. Это исходный код обновления; сервер пользователя автоматически не обновлён.

Нагрузка 1000 участников конференций этим обновлением не проверялась. Доставка внешних сообщений имеет семантику at least once; возможные дубли после неопределённого сетевого результата описаны в руководстве.
