# Выбор базы данных и очистка рабочей папки

25 сентября 2026. Владелец запросил очистку лишних логов и временных файлов,
а также сборку с PostgreSQL и возможностью выбора БД. Это явно заменяет прежнее
ограничение на использование только MySQL. MySQL остаётся вариантом по умолчанию.

## Объём и порядок работ

- [x] Удалить проверенные временные логи и отчёты внутри проекта; сохранить
  `.env`, исходники, зависимости для сборки, историю Git и пользовательские данные.
- [x] Проверить обращения к БД, транзакции, миграции, блокировки, очереди,
  поиск, учёт идентификаторов и резервное копирование.
- [x] Добавить выбор MySQL/PostgreSQL через окружение и единый слой подключения.
- [x] Подготовить отдельные миграции PostgreSQL с эквивалентными ограничениями,
  индексами и проверками целостности. Выпущенные MySQL 001–043 не менять.
- [x] Проверить работу на двух настоящих одноразовых БД: начальные данные,
  вход, задачи, планирование, знания, чат, ИИ, интеграции и сохранение файлов.
- [x] Добавить варианты Docker Compose и Helm, примеры окружения, миграции,
  резервирование, документацию выбора БД и проверки CI.
- [x] Пройти серверные тесты, quality, сборку, браузер, UTF-8 и проверку Git.
- [ ] Опубликовать изменения в согласованный main и проверить CI.

Подтверждены 335 серверных тестов, по 24 браузерных сценария на каждой БД,
1204 запроса PostgreSQL, интеграционные сценарии и восстановление 186 таблиц
для каждой БД. Собран образ `kontur-work:0.22.0`; установка PostgreSQL проверена
без административных прав у пользователя приложения. Compose и Helm lint
проверены для обоих вариантов. Подробнее: [релиз](RELEASE-0.22.0.md).

Выбор БД относится к установке целиком и применяется при запуске процессов.
Изменение настройки само не переносит существующие данные. Не запускать миграции,
seed или очистку на рабочей БД. Проверки выполняются на изолированных стендах.
Не выводить значения секретов из `.env`. Нужность переноса существующих данных
уточняется отдельно; независимая работа над новой установкой продолжается.
