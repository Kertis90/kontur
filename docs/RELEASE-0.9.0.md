# Контур Work 0.9.0

ИИ, опциональная запись встреч в S3 и управление проектными доступами.

## Изменения

- Несколько профилей ИИ со своими endpoint, протоколами, ключами и моделями; загрузка списка моделей и проверка подключения.
- Оценка проекта, сводка чата конференции и изложение аудиозаписи. Фоновая очередь, сохранённые результаты и повторное использование неизменного контекста.
- Запуск и остановка записи по кнопке, индикатор участникам, приватный S3, просмотр и скачивание MP4.
- Отдельный worker распознавания, нарезка аудио по десять минут, кэш обработанных частей и общая готовая расшифровка.
- Права на запись, просмотр, ИИ и его настройку; отдельные API scopes и повторная проверка прав в очередях.
- Прямые и групповые назначения доступа к проекту, проверка прав сотрудника, редактирование проекта, архив, корзина и восстановление.
- Поиск сотрудников и флажки в редакторе состава группы.
- Новые компоненты Compose/Helm, ffmpeg в контейнере, документация API и руководства.

Подробные сценарии и ограничения: [ИИ, записи и доступ](AI-RECORDINGS-ACCESS.md).

## Обновление

1. Завершите активные встречи и записи; сохраните резервные копии MySQL/S3 и ключ шифрования.
2. Соберите образ `0.9.0`. Для готового registry-образа обновите `KONTUR_IMAGE` или Helm `image.tag`.
3. В Kubernetes с внешним Secret добавьте `EGRESS_CONFIG_BODY` по примеру из chart. Закрепите проверенную версию Egress и выделите ресурсы его pod и временного диска worker.
4. Запустите штатное обновление Compose или Helm. Миграции `010_ai_and_project_access.sql` и `011_conference_recordings.sql` выполняются до запуска приложения.
5. В интерфейсе настройте ИИ и распознавание, затем выдайте права нужным ролям.

```bash
docker compose up -d --build --wait
docker compose ps
docker compose logs --tail=100 recording-worker egress worker
```

После применения миграций не возвращайте старое приложение без оценки совместимости: версия 0.8.0 не учитывает корзину проектов. Rollback схемы и данных выполняется из проверенной резервной копии.

## Проверка этой версии

- Production-сборка Next.js.
- Статические проверки качества, PWA, API-каталога и состава deployment-файлов.
- Тесты существующего чата конференций и новых прав, адаптеров ИИ, API-политик, записи и кэша расшифровки.
- Реальная обработка ffmpeg тестового MP4 длительностью 10 минут 1 секунда: два фрагмента, первый взят из кэша, второй отправлен тестовому STT-адаптеру.

В этой среде нет работающих MySQL, Docker, Helm и LiveKit Egress. Миграции на реальной БД, запуск контейнеров/кластера, видеозапись в S3 и генерация на выбранном вами провайдере требуют проверки в вашей инсталляции. Браузерная проверка интерфейса также не выполнялась: доступный preview не может запустить сервер платформы. Нагрузочный тест на 1000 участников не проводился.
