# Согласованный пакет развития после 0.13.0

Все пункты ниже одобрены пользователем. Работа продолжается; отметки означают состояние реализации, а не испытания внешней инфраструктуры.

- [x] CalDAV: личные подключения, выбранные встречи, условная запись ETag, обмен изменениями и собственным ответом участника, разбор конфликтов.
- [x] SLA: предупреждения, нарушения и эскалации по рабочим минутам, адресаты и события для интеграций.
- [x] Действия интеграций в автоматизациях с отдельным правом и предварительным просмотром.
- [x] GitLab: связи с существующими задачами, сопоставление открытого/закрытого этапов и исполнителей, двусторонний обмен и конфликты.
- [x] Контроль интеграций: состояния доставки, оповещения об ошибках/восстановлении, история настроек.
- [x] Тест-кейсы, планы, прогоны, связь с задачами/релизами и приём результатов автотестов.
- [x] Цели и OKR со связями проектов и задач.
- [x] Семантический поиск по задачам, знаниям и расшифровкам с актуальными правами.
- [x] Расширенный импорт Jira с историей, вложениями, связями, проверкой и возобновлением.
- [x] Резервное копирование/восстановление, мониторинг и нагрузочные сценарии конференций.
- [x] Общая документация API и финальная проверка кода 0.14.0. Версия и архив формируются из итогового коммита.

Текущие ограничения календарей: одна неповторяющаяся встреча на объект, полные даты UTC/TZID; не поддерживаются серии и вложенные компоненты. Изменение параметров встречи требует прав организатора/управляющего и состояния scheduled. Удаление внешнего объекта не удаляет встречу или задачу в Контуре. Подключения и ссылки удаляются отдельно от самих объектов.

GitLab синхронизирует title, description, due_date, одного исполнителя и два сопоставленных этапа. Для первого объединения различающихся объектов пользователь выбирает версию. GitLab Issues API не предоставляет используемой здесь гарантии атомарного compare-and-swap; выполняются повторная проверка перед записью и сверка после, но исключить все гонки внешних клиентов нельзя.

Миграции 022–029 новые; старые миграции не изменяются. Проверки транспорта и доступа выполняются с заглушками. Реальные CalDAV/GitLab/MySQL и отображение требуют стенда.

Итоговые границы возможностей и проверки: [RELEASE-0.14.0.md](RELEASE-0.14.0.md). 179 тестов, production-сборка и проверка качества прошли; внешняя инфраструктура и 1000 участников на стенде не проверялись.
