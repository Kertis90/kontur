# Контур Work 0.19.0

## Изменения

- Исправлено падение разделов «ИИ-агенты» и «Комнаты»: они использовали
  отсутствующий раздел прав. Создание и настройка агента сразу открывают
  визуальную схему. «Вписать» учитывает границы блоков, сохраняя читаемость
  короткого сценария на телефоне.
- Добавлен [переезд с Jira](JIRA-TRANSFER.md): подключение Data Center/Cloud,
  соответствия, предварительная проверка, фоновые проходы, файлы, история,
  связи между страницами, повторное обновление, конфликты и итоговое переключение.
- «Начать работу» ведёт через организацию, сотрудников, проект, импорт и задачу.
  Название организации сохраняется с проверкой прав и одновременных изменений.
- Часы выделены из главного экрана: секундный таймер обновляет только часы,
  а не пересоздаёт весь экран с доской. Новая логика переноса и первых шагов
  находится в отдельных небольших модулях.
- Добавлены GitHub Actions, проверки браузера на компьютере и телефоне,
  отдельные MySQL/Redis/S3, перенос Jira и восстановление зашифрованной копии.
- Ссылки на MinIO и его клиент в Compose заменены на доступный официальный
  реестр Quay с закреплёнными версиями; сервер соответствует версии,
  проверенной на локальном стенде. Можно указать собственные `MINIO_IMAGE`
  и `MINIO_CLIENT_IMAGE`. Helm по-прежнему использует внешнее S3-хранилище.
- Проверка восстановления выявила ошибку завершающего `;` в триггерах выгрузки
  MySQL. Восстановление теперь исправляет только внешний завершитель такого
  блока после проверки подлинности архива. Данные и исходные миграции сохранены.
  Основание: [подтверждённая ошибка клиента MySQL](https://bugs.mysql.com/bug.php?id=77856).

## Обновление

Поставка содержит новую миграцию `036_jira_transfer.sql`. Миграции 001–035
не изменены. Сохраните резервную копию и ключи шифрования, остановите процессы
записи, примените обновление по [DATABASE-UPGRADES.md](DATABASE-UPGRADES.md).
Не используйте демонстрационный seed для существующей установки.

Compose и Helm сохраняются; используйте собственный собранный образ 0.19.0.
Публикация исходников в GitHub не обновляет уже запущенный контейнер.
Миграция проверена на отдельной MySQL; обновление вашей рабочей базы не выполнялось.

Новые подключения используют существующий worker, настройки разрешённых
внутренних адресов, шифрование и S3. Настройки реальной Jira вводятся в интерфейсе
администратором. Автоматические тесты не изменяют рабочую Jira и базу пользователя.

## Проверки и ограничения

Результаты итогового прогона записаны в [IMPROVEMENT-PLAN.md](IMPROVEMENT-PLAN.md).
Браузерные измерения служат ориентиром отдельного локального стенда с небольшим
числом задач, не подтверждают скорость на рабочих объёмах или на реальном телефоне.
Внешние Jira, ИИ-провайдеры, LiveKit, корпоративный вход, нагрузка и установка
Helm остаются отдельными проверками эксплуатации.
