# Контур Work 0.22.1 — зеркала источников сборки

Сборка в закрытом контуре: адреса внешних пакетов и исходников задаются
параметрами. Возможности 0.22.0 сохранены полностью, новых SQL-миграций нет,
MySQL 001–043 и PostgreSQL 001–002 не изменены. Поведение по умолчанию прежнее:
без заданных параметров используются те же публичные адреса, что и раньше.

## Что добавлено

Все параметры необязательны и задаются через `.env` или `--build-arg`.

| Параметр | Что перенаправляет |
| --- | --- |
| `NPM_REGISTRY` | реестр npm для образа приложения |
| `ALPINE_MIRROR` | пакеты Alpine (ffmpeg); указывается базовый адрес, версия выпуска и разделы `main`/`community` подставляются из образа |
| `DEBIAN_MIRROR`, `DEBIAN_SECURITY_MIRROR` | пакеты Debian для сборки хранилища |
| `GO_PROXY`, `GO_SUMDB` | модули Go для сборки MinIO и `mc` |
| `ARCHIVE_BASE` | исходники MinIO и `mc` вместо `codeload.github.com` |
| `MINIO_SOURCE_URL`, `MC_SOURCE_URL` и парные `_SHA256` | полные адреса, если архивы выложены на внутреннем хранилище под своими именами |

Образы контейнеров в этот список не входят: они настраиваются зеркалом реестра
или переменными `KONTUR_IMAGE`, `MINIO_IMAGE`, `MINIO_CLIENT_IMAGE`,
`LIVEKIT_EGRESS_IMAGE`, которые существовали и раньше.

Файл репозиториев Debian переписывается в формате deb822; подпись остаётся
дебиановской, поэтому зеркало должно быть точной копией репозитория. Модули Go
по-прежнему проверяются по `go.sum` из самих исходников, а архивы MinIO и `mc` —
по SHA-256 до распаковки. Проверки целостности не ослаблены.

## Два ограничения при настройке

Зеркало Debian указывайте по `http`. Стадия сборки хранилища сама устанавливает
`ca-certificates`, и до этого момента в образе нет корневых сертификатов: зеркало
по `https` с внутренним УЦ остановит `apt-get update` ошибкой проверки сертификата.
Целостность обеспечивают подписи GPG — по этой же причине Debian раздаёт свои
репозитории по обычному http.

Архивы исходников MinIO копируйте побайтно. `ADD --checksum` сверяет SHA-256 до
распаковки, а архив тех же коммитов, пересобранный другим сервисом (GitLab, Gitea),
даст другую сумму и остановит сборку. Если архив всё же пересобран, проверьте его
самостоятельно и задайте `MINIO_SOURCE_SHA256` / `MC_SOURCE_SHA256`.

## Проверки

Пройдены 335 серверных тестов, `npm run quality` и production-сборка Next.js
на Node 24.14.1. Проверка качества подтверждает совпадение версии в `package.json`,
lock-файле, OpenAPI и Helm chart.

Отдельно проверены сами механизмы подстановки: формат файлов репозиториев внутри
`debian:bookworm-slim`, `golang:1.24.13-bookworm` и `node:22-alpine`; раскрытие
переменных BuildKit в адресе и во флаге `--checksum`; поведение Compose с
аргументом без значения, при котором адрес по умолчанию из Dockerfile сохраняется.
Собрана стадия `runtime` хранилища: с параметрами по умолчанию файл репозиториев
получается идентичным исходному, с заданным зеркалом apt обращается к нему.
Строка установки ffmpeg проверена в Alpine, подстановка зеркала сохраняет путь
`/v3.24/main` и `/community`.

## Что не проверялось

Полная сборка хранилища с компиляцией MinIO и `mc`, а также сборка образа
приложения целиком здесь не выполнялись — проверены стадии, которых касались
изменения. Реальный внутренний прокси не подключался: подстановка адресов
проверена на недостижимых тестовых хостах и на публичных адресах по умолчанию.
Рабочая установка этим выпуском не обновлялась.
