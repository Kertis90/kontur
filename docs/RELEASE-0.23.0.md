# Контур Work 0.23.0

Компания теперь объединяет трайбы с собственными названиями, лидерами,
сотрудниками и проектами. Лидер создаёт пространство и делегирует права внутри
него. Новые проекты закрыты по умолчанию; создатель становится владельцем.

- **Трайбы**: состав, оформление, четыре делегируемых права, передача руководства,
  переключение пространства и распределение существующих проектов администратором.
- **Участники и доступ**: личные и групповые назначения, передача владения,
  защита владельца от удаления, проверка фактических прав. Создание и изменение
  групп требуют отдельного права управления группами.
- **Согласования ИИ**: отдельная очередь сотрудника, исходные данные и решения
  через существующие проверки прав, срока, версии и состояния сценария.
- **Сборка**: сохранены изменения зеркал из 0.22.1; добавлены выбор базовых образов
  Node.js/Go/Debian и адрес заголовков Node.js. Обновлены `.env.example`, Compose,
  версия Helm и руководства.

Миграции: MySQL `044`, PostgreSQL `003`. Старые проекты сохраняют прежнюю схему
доступа до явного закрытия или назначения трайба. Применение миграций к рабочей
установке — отдельный шаг обновления после резервного копирования.

## Проверки

На Node.js 22.23.2 прошли 342 серверных теста, quality и production build.
Обе БД прошли полный набор интеграционных проверок: права и их отзыв, планирование,
ИИ, существующий перенос данных, резервные копии. При восстановлении совпало
содержимое 188 таблиц каждой БД. Проверка PostgreSQL разобрала 1231 SQL-запрос
без ошибок; 106 динамических фрагментов пропущены сканером и проверяются
соответствующими интеграционными сценариями там, где они используются.

На каждой из двух БД пройдены 32 браузерных сценария на компьютере и телефоне.
Проверены создание трайба и группы, делегирование, владение проектом,
личный доступ, решение сотрудника, а также прежние конструктор, чат и планирование.

Собран итоговый образ `kontur-work:0.23.0`:
`sha256:5e7a7026c0949b224fee6d05d9f22e7b4d1705dfa7a2b2e988c3f40039d25f3e`.
Из образа проверены соединение и журнал миграций обеих тестовых БД без записи.
Собраны MinIO и клиент из исходников с настройками apt/Go по умолчанию.
Строгая проверка Helm пройдена с обоими движками и резервным копированием.
Compose передаёт 13 проверенных параметров зеркал и источников из тестового
файла окружения. Проверка UTF-8 и `git diff --check` пройдены.

Код опубликован в `main`: [`0aabd84`](https://github.com/Kertis90/kontur/commit/0aabd843ac14c0b1abbe067837bb18cb6a94a752).
