# Прокси и закрытая установка

Задача владельца: проверить собственные источники пакетов для Docker и Kubernetes
и предложить дальнейшее развитие продукта. Подтверждены оба варианта подключения:
внутренние репозитории пакетов и HTTP/HTTPS-прокси. Реальные адреса пока не заданы.

- [x] Проверить Dockerfile, Compose, Helm и действующие параметры зеркал.
- [x] Передавать стандартные HTTP_PROXY/HTTPS_PROXY/NO_PROXY/ALL_PROXY в сборку
  приложения и хранилища без сохранения в окружении готового образа.
- [x] Исправить передачу imagePullSecrets всем компонентам Kubernetes.
- [x] Дать согласованные примеры Docker и Kubernetes для закрытого реестра
  и объяснить настройку прокси сборщика и узлов кластера.
- [x] Проверить фактические параметры Compose, отрисованные манифесты Helm
  и прохождение запросов сборки через отдельный тестовый прокси.
- [x] Проверить соседние функции, сборку и UTF-8.
- [ ] Опубликовать исправления и проверить результат CI.
- [x] Сохранить предложения по развитию с учётом уже работающих возможностей.

Результаты проверок: [RELEASE-0.23.1.md](RELEASE-0.23.1.md).
Предложения: [NEXT-IMPROVEMENTS.md](NEXT-IMPROVEMENTS.md).

Рабочие настройки Docker, Kubernetes, БД и чужие проекты не изменять.
Секреты и внутренние адреса не публиковать. Никакие новые продуктовые функции
из предложений не реализовывать без выбора владельца.
