# Контур Work 0.18.0

## Что изменилось

- Постоянные комнаты чата с нулём участников при создании, открытием по политике рабочего пространства/проекта/приглашения, входом и выходом, архивом и сохранением истории.
- Графический canvas ИИ-сценариев: перетаскивание блоков, связи, масштабирование, клавиатурное перемещение и трасса выполнения.
- Черновики и опубликованные версии агентов, тест черновика, публикация с optimistic locking.
- Служебные учётные записи агентов со scoped project/workspace ACL, разрешёнными моделями и источниками, владельцем, бюджетом и экстренным отключением.
- Сохраняемые human approval gates и возобновление после рестарта worker.
- Генератор агента по текстовому описанию, лаборатория сравнений версий и детерминированные проверки.
- ACL-проверенный семантический источник, цитаты, предпросмотр действий «до/после» и четыре практических шаблона.

## Обновление

Остановите app, worker и recording-worker, выполните `scripts/migrate.mjs --status`, затем `scripts/migrate.mjs` в существующей базе и поднимите тот же Compose/Helm release с образом 0.18.0. Не используйте `down -v`. При ошибке DDL следуйте `docs/DATABASE-UPGRADES.md`.

## Проверки

279 серверных тестов в 29 файлах, production build Next.js и quality-check. MySQL, Docker, Helm CLI и Chromium в среде проверки отсутствуют; миграция на рабочей базе, деплой и ручной браузерный прогон требуют вашей инфраструктуры.
