# Контур Work 0.12.0

Обновление оформления по запросу пользователя с ориентиром на mts.ru и исправление поля ввода чата конференции. Включает исправление миграции `013` из 0.11.1.

## Оформление

- Светлая боковая навигация, тёмные заголовки, красные основные действия, округлые белые карточки на нейтральном фоне.
- Единые цвета акцентов для проектов, доски, дашбордов, администрирования, базы знаний, API, ИИ и коммуникаций. Цвета акцентов вынесены в переменные `--brand-*`; прежние переменные `--purple-*` остаются совместимыми именами.
- Обновлены размеры и насыщенность заголовков, состояния кнопок, активные разделы, тени и рамки. Основной красный для кнопок затемнён до `#d9002b`: контраст белого текста 5,27:1. Яркий `#ff0032` используется в знаке и декоративных акцентах.
- PWA получила обновлённые SVG/PNG-иконки и цвет верхней панели. Версия кэша оболочки изменена, чтобы приложение обновило оформление.
- Сохранён знак «Контур». Типографика использует локальные системные шрифты, загрузка шрифта с внешнего сервера не требуется. Цвета проектов и этапов, заданные в данных пользователем, остаются отдельными настройками.

Референс: [официальная главная МТС](https://moskva.mts.ru/personal) и [описание бренда МТС](https://ar2023.mts.ru/). Главная доступна через поиск, но прямое открытие в браузере подготовки вернуло блокировку доступа. Это самостоятельная адаптация визуального направления для рабочего приложения, а не подтверждение точного совпадения с текущей страницей МТС.

## Чат конференции

Причина сжатия: конференция использовала сетку из трёх строк, затем между заголовком и рабочей областью появились субтитры и уведомления. Рабочая область попадала в строку высотой нижней панели, а панель управления уходила в неявную строку сетки.

- Окно теперь распределяет высоту между заголовком, ограниченной по высоте областью субтитров/уведомлений, рабочей областью и нижними кнопками. Рабочая область занимает оставшееся место.
- Панель чата отделяет прокручиваемые сообщения от формы ввода. Ошибка синхронизации находится в потоке, а не поверх текста сообщений.
- Четыре вкладки конференции расположены в одной прокручиваемой строке; чат идёт первым. Вкладки не переносятся в дополнительные строки и не перекрывают кнопку закрытия.
- Поле ввода автоматически растёт до ограниченной высоты, длинный текст прокручивается внутри него. Кнопка отправки имеет собственное место и высоту 44 px.
- Высота окна учитывает `visualViewport` и открытие мобильной клавиатуры. При малой высоте кнопка отправки находится рядом с полем, а служебные блоки становятся компактнее. Масштабирование страницы не запрещено.

История, сохранение сообщений, вопросы, отправка по Enter на компьютере и перенос по Shift+Enter продолжают использовать существующие API. На телефоне Enter сохраняет перенос строки.

## Обновление

Используйте один образ 0.12.0 для приложения, обоих worker и migrate; значения Helm обновлены. В Compose сохраняйте `.env`, имя проекта и рабочие тома. Новых файлов миграций в этом обновлении нет. При незавершённой `013` используйте [инструкцию восстановления](DATABASE-UPGRADES.md), исправление 0.11.1 включено.

Контракт API по методам не менялся; `/api/openapi.json` сообщает текущую версию 0.12.0. Иконка уже установленного PWA может обновиться только после перезапуска или обновления приложения самим браузером.

## Проверка

Прошли сборка Next.js, проверка шести CSS-файлов и UI/PWA/API-контрактов, проверка переменных темы и контраста основных пар цветов, а также 27 существующих тестов конференций. PNG-иконки получены из обновлённого SVG.

Браузерная и мобильная проверка на целевом устройстве не проведена: `sites-previewd` недоступен в среде подготовки. MySQL/LiveKit и Docker/Helm здесь не запускались. Самостоятельный Node.js/MySQL-продукт этим коммитом не развёрнут на прежнем демонстрационном сайте или сервере пользователя.
