# Владельцы проектов и доступ сотрудников

25 сентября 2026. Новые проекты доступны только владельцу, назначенным сотрудникам
и группам; системные владельцы и администраторы сохраняют доступ. Создатель становится
владельцем автоматически. Группы создают и редактируют только сотрудники с правом
управления группами, включая системных администраторов.

Уточнение владельца: структура компании — «компания → трайбы → проекты».
Компания остаётся текущим рабочим пространством; каждый трайб получает своё
название, лидера, состав и отдельные права настройки. Трайб-лидер управляет только
своим трайбом и может делегировать ограниченные права его участникам, не меняя
глобальные роли и чужие трайбы. Старые проекты не переносить произвольно:
показать их администратору как ещё не распределённые и дать явное назначение трайба.
Новые проекты создаются внутри выбранного трайба.

Дополнительно: нужен заметный раздел ожидающих согласований ИИ с проверкой
согласующего, актуальных прав и версии запроса. Исполнение использует существующие
защищённые методы согласования, а не отдельный обход проверки.

Изменения деплоя пользователя сохранены в `f094924` (0.22.1). Проверить передачу
зеркал apk, apt, Go и npm/образа Node.js через Compose, примеры окружения и сборки.
Не перезаписывать пользовательские адреса и не отключать проверку сертификатов.
