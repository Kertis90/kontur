## Ограничения

Публикация исходников разрешена пользователем. Рабочая БД и другие проекты
не изменяются. История удалённого репозитория сохраняется без принудительной
перезаписи. Новые функции, включая синхронизацию Jira, пока только предлагаются.
`SOURCE-MANIFEST.json` остаётся описанием исходного архива передачи;
новые документы не меняют его исторические контрольные суммы.

Пользователь уточнил цель: постепенный переход с Jira в Контур. Предложения
в [PROJECT-REVIEW.md](PROJECT-REVIEW.md) ориентированы на переезд по проектам.

Репозиторий доступен; перед первой отправкой удалённых веток нет. Используется
уже выбранная локальная ветка `main` и существующий адрес `origin`.

Замечания к пробелам оставлены в первом импорте для сохранения исходников.
Они не затрагивают миграции. Документы текущей задачи проходят отдельную
проверку `git diff --cached --check -- README.md docs/HANDOFF.md docs/PUBLISH-PLAN.md docs/PROJECT-REVIEW.md`.

Поиск секретов по характерным шаблонам не является полным аудитом безопасности.
Процент покрытия тестами не измерялся. Отдельная проверка TypeScript неприменима:
проект написан на JavaScript; проверка сборки выполнена штатной командой.

Из исходных файлов изменены только `README.md` и `docs/HANDOFF.md`:
добавлены ссылки и контекст текущей задачи. Добавлены этот план и
`docs/PROJECT-REVIEW.md`. Код приложения, соседние методы, договорённости API,
зависимости и миграции не менялись; весь существующий набор тестов пройден.
В первую публикацию подготовлено 359 файлов.

Не выполнялись запуск приложения с MySQL/Redis/S3, миграции живой БД,
развёртывание Docker/Helm, браузерные сценарии, подключения Jira/LiveKit/ИИ
и нагрузочные проверки. Публикация исходников не означает развёртывание сайта.

Результат отправки и сверки удалённого коммита будет добавлен после публикации.
